案例：Token Forest 官网

Token Forest 是 Poietic Studio 发布的一款像素风桌面应用，我们两人都是 Poietic Studio 的成员。它的官网 tokenforest.com.au 由我们设计和开发。

1. 为应用建立官网

Token Forest 面向 Windows 和 macOS。公开介绍说明它把 Claude Code 与 Codex 消耗的 token 变成一棵会长大的像素树。官网把介绍、下载与全球排行榜放在一起，让访客了解应用并找到公开资料。

我们负责的是官网：页面、视觉设计、多语言和公开数据功能。

访问 Token Forest 官网

2. 我们制作的页面

产品介绍连接独立下载页。全球排行榜有多个榜单，玩家也有展示森林及榜单信息的公开页面。网站因此不只是单张宣传页，访客还可以了解产品并浏览公开内容。

README 徽章页介绍自愿加入排行榜的玩家可使用的嵌入图片。隐私、条款和安全说明页与产品信息一起提供，让读者不只依赖简短介绍来了解公开说明。

3. 像素花园的视觉表达

官网采用像素花园风格，使用真实像素素材。树木、花园配色与像素字形，把产品介绍和其他公开页面连接起来。首页截图展示这种视觉语言如何介绍应用，徽章页截图则展示它在实用说明中的延续。

4. 四种语言与专题内容

英文、中文、日文、韩文各有独立网址。网站按浏览器语言偏好选择版本，也提供语言切换。截图为英文版。

官网另有面向相关搜索主题的专题页，包括 Claude Code 费用、使用限制和 Codex 用量追踪。相关问题各有说明，不把所有内容挤在首页。

5. 公开数据与自愿参与

排行榜数据由 Supabase 的 Postgres 提供。玩家自行选择是否加入排行榜，官网有公开说明。玩家页面和嵌入徽章为公开信息提供不同展示方式。

6. 对业务网站的启发

同一个视觉体系里，可以组合多语言、带数据的页面、可分享内容和清楚的隐私说明。Token Forest 官网展示了这些内容的组合。其他商家应先判断哪些能力解决实际顾客需求，不照搬应用主题，也不默认需要相同功能清单。

本官网使用 Next.js 的 App Router 与 TypeScript，Tailwind CSS 负责视觉样式，next-intl 组织多语言，并部署在 Netlify。新项目的平台会在评估后另行选择。

7. 访问官网

通过官网查看介绍、语言切换、下载信息和公开页面。下方链接指向 tokenforest.com.au。
